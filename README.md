# Minesweeper

A simple Minesweeper game written in C++ for my Programming Fundamentals course.

## Features

* Beginner, intermediate, and expert difficulty levels
* Custom board size and number of mines
* Flag placement
* Save and load games
* Leaderboard and scoring
* Colored terminal interface

## Controls

* `W A S D` — Move
* `Space` — Reveal a cell
* `F` — Place/remove a flag
* `O` — Save the game
* `Q` — Quit

## Built With

C++ and CLUI (Command Line User Interface)
